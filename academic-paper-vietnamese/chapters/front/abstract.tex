\begin{preface}{Tóm tắt}
Luận văn này đề xuất một framework end-to-end hỗ trợ phát triển mô hình AI cho nhận dạng hoạt động con người (HAR) trên thiết bị biên tài nguyên hạn chế. Động lực chính là thu hẹp khoảng cách giữa huấn luyện và triển khai, vốn thường đòi hỏi nhiều thao tác thủ công và kiến thức liên ngành về tiền xử lý, trích xuất đặc trưng, huấn luyện mô hình và tối ưu mã nhúng. Framework cung cấp quy trình GUI trực quan, cho phép người dùng lựa chọn đoạn tín hiệu theo cơ chế kéo thả, cấu hình trích xuất đặc trưng, huấn luyện mô hình và sinh mã triển khai trong cùng một hệ thống.

Hệ thống hỗ trợ các thuật toán Random Forest, SVM, Neural Network, PyTorch MLP và PyTorch 1D-CNN; đồng thời hỗ trợ nhiều đích triển khai như Arduino-compatible, ARM Cortex-M, ESP-IDF, MicroPython và Zephyr. Kiến trúc generator phân tầng theo mô hình, nền tảng và backend giúp tái sử dụng pipeline huấn luyện cho nhiều mục tiêu triển khai, với các chế độ tối ưu hóa theo độ chính xác, tốc độ, năng lượng hoặc cân bằng. Trên bộ dữ liệu HAR 5 lớp thu thập ở 100Hz từ IMU 6 trục (LSM6DS3), các mô hình đạt 97,38--99,13\% trên tập kiểm tra; kết quả cao nhất thuộc về PyTorch MLP và PyTorch 1D-CNN (99,13\%). Đánh giá trên thiết bị tham chiếu cho thấy PyTorch 1D-CNN đạt 99,4\% với tỷ lệ từ chối 0,6\%. So với các nền tảng thương mại như Edge Impulse và SensiML, framework đề xuất nổi bật ở tính minh bạch, khả năng tùy biến tiền xử lý và chi phí nền tảng bằng không.
\end{preface}

\begin{preface}{Abstract}
This thesis presents an end-to-end framework for developing human activity recognition (HAR) models on resource-constrained edge devices. The main objective is to reduce training-to-deployment friction, which typically requires significant manual work across preprocessing, feature extraction, model training, and embedded implementation. The framework provides an integrated GUI workflow where users can interactively select signal windows, configure features, train models, and generate deployment code within a single environment.

The system supports Random Forest, SVM, Neural Network, PyTorch MLP, and PyTorch 1D-CNN, and targets multiple runtimes and platforms, including Arduino-compatible boards, ARM Cortex-M, ESP-IDF, MicroPython, and Zephyr. A hierarchical code generation architecture (model-platform-backend) enables reuse of the same training artifacts across deployment targets, with optimization modes for accuracy, speed, power, and balanced trade-offs. On a 5-class HAR dataset sampled at 100Hz from a 6-axis IMU (LSM6DS3), models achieve 97.38--99.13\% test accuracy; the best results are obtained by PyTorch MLP and PyTorch 1D-CNN (99.13\%). On-device evaluation on a reference platform reports 99.4\% accuracy and a 0.6\% rejection rate for PyTorch 1D-CNN. Compared with commercial tools (Edge Impulse and SensiML), the proposed open-source framework provides stronger transparency, greater preprocessing flexibility, and zero platform cost.
\end{preface}
